# SaludPredict AI

Sistema inteligente de recomendación hospitalaria y asistencia médica conversacional impulsado por IA.

---

# Demo en línea

## Acceder al sistema

[SaludPredict AI - Demo Web](https://copai-ai-agente-conversacional-copa.vercel.app/?utm_source=chatgpt.com)

---

# Cómo usar la página

1. Ingresa al enlace del sistema.
2. En la pantalla principal presiona el botón:

```text id="ib7v9x"
Empezar ahora
```

3. El sistema abrirá el dashboard principal del paciente.
4. Escribe un síntoma o consulta médica en el chat IA.
5. El agente inteligente analizará el caso y recomendará hospitales según la especialidad requerida.

Ejemplos de consultas:

* “Me duele la cabeza”
* “Tengo dolor de estómago”
* “Fiebre y tos”
* “Dolor en el pecho”

---

# Descripción

SaludPredict AI es una plataforma web que combina inteligencia artificial y experiencia de usuario para ayudar a pacientes a:

* Consultar síntomas mediante IA.
* Recibir recomendaciones hospitalarias.
* Visualizar coberturas del seguro.
* Obtener orientación médica inicial.
* Gestionar información del paciente desde un dashboard intuitivo.
